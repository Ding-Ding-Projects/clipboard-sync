# Application integration contract

Version 0.1.0. Windows 10/11 is the native target. Python 3.12+, aiohttp and Pillow are the application runtime; UI bundles locally with Vite and genuine @material/web controls. No private instruction vocabulary in source.

## Ownership

- `receiver/`, `tests/test_receiver.py`, `requirements.txt`: Windows receiver lane.
- `web/`, `package.json`, `package-lock.json`, `design/`: UI lane.
- `sync_server/`, `server.Dockerfile`, `compose.yaml`, `.dockerignore`, `tests/test_sync_server.py`, `server-requirements.txt`, `host.bat`, `scripts/host.ps1`: sync server lane.
- Other root files, scripts, documentation and CI: integration owner.

## Receiver

Run `python -m receiver` (Windows) or `python -m receiver --headless --port 5333` (Linux transport testing only). Bind LAN 0.0.0.0:5333; open desktop browser `http://127.0.0.1:5333/#admin=ADMIN_TOKEN`. Serve Vite `dist/` locally. Admin token and mobile token are distinct 256-bit random secrets, never log. `/send#token=MOBILE_TOKEN` is the phone link. Tokens stay in fragments and go in `Authorization: Bearer TOKEN`, never query. Origin checks reject foreign-origin writes. Desktop-only admin setup can return mobile token. QR generated by frontend qrcode library.

GET `/api/status` (admin): `{deviceName, platform, clipboardAvailable, phoneConnected, paused, pairUrl, receivedToday, historyCount, sync:{enabled,url,connected,error}, setupComplete, version}`.
GET `/api/history?type=all|text|image|file&q=...` (admin): `{items:[{id,type,name,preview,size,createdAt,source,status}],total}` newest first, limit 100. No tokens in history.
POST `/api/transfer` (mobile or admin), JSON `{type:'text',text:'...',deviceName:'Phone'}` or `{type:'image'|'file',name:'...',mime:'...',data:'BASE64',deviceName:'Phone'}`. 25 MiB max binary/100k text. Returns `{ok:true,id,copied:true}` ONLY after clipboard copied; headless responds copied:false and clear status. Phone upload image unsupported formats fall back file. Mobile GET `/api/phone` -> `{deviceName,clipboardAvailable,paused,maxFileBytes,version}` and marks connected.
POST `/api/history/ID/restore` (admin) returns `{ok:true,copied:true}` only real copy.
POST `/api/settings` (admin) JSON optional `{paused,setupComplete,sync:{enabled,url,token,room}}`; empty token preserves configured secret. response status. Persist setup and nonsecret settings; secrets outside Git history with user-only permissions.
POST `/api/pair/reset` (admin) rotates phone token, returns status; desktop token remains.
GET `/api/history/ID/file` admin downloads original image/file. GET `/api/history/ID/detail` admin -> text/full metadata for details.
POST `/api/history/clear` admin requires `{confirm:true}`; clear visible history while Git retention is explained honestly.
GET `/api/events` admin SSE optional; UI can poll status/history every 2s.
Errors JSON `{error:'human-readable'}` with correct HTTP status. Content security / no cache on API. Browser local settings for theme/language persist.

## Durable history

Store received AND locally detected clipboard changes in `%LOCALAPPDATA%/ClipboardSync/history` as a genuine local Git repository; metadata and content committed per new entry; fail visibly if Git unavailable. Windows clipboard polling reads sequence number plus Unicode text/bitmap/file drop data. Deduplicate content and suppress server echo. Do not execute received files. History is local, never `git push`. App settings/token caches excluded. Keep clipboard writes serialized. In headless mode never claim native Windows success.

## Relay protocol

`GET /health` -> JSON status. `GET /ws/ROOM` WebSocket with Authorization Bearer shared SERVER_TOKEN. Optional welcome `{type:'ready'}`. Client sends `{type:'clipboard',id:UUID,origin:DEVICE_UUID,createdAt:ISO8601,payload:{type:'text',text:'...'}|{type:'image'|'file',name,mime,data}}`. Relay broadcasts valid events to other room members and optional ACK `{type:'ack',id}` to sender. 25 MiB binary; encoded message capped 36 MiB. Reject invalid names/rooms/type, authenticate before upgrade, dedupe event ids bounded; client handles reconnect exponential backoff, no sync loop, offline local use. Relay stores no clipboard content on disk. `GET /` hosts server status/docs setup page, never exposes configured secrets. Bind 0.0.0.0:8787.
